## eblobs

what does this do you may ask?, well

- 1. gets your email messages depending on your email

- 2. creates emails.html

and etc.

list of email providers that are supported:

- gmail

- yahoo mail

- outlook / hotmail / live / MSN / office 365

- AOL

- icloud mail

- zoho mail

- yandex

- mail.ru

- GMX

- web.de

- fastmail

also has a shell.nix for nixos

to install you will need gcc, cmake, and openssl

```
git clone https://github.com/shoko3756/eblobs
cd eblobs
make run
```

or for nixos

```
git clone https://github.com/shoko3756/eblobs
cd eblobs
# enter the shell.nix by doing nix-shell
make run
```
